---
title: autos.reset
description: "Resets the caller's autocompletes"
---

((autos.reset)) clears out all of the caller's autocompletes.

### Security level

MIDSEC

## Syntax

### CLI

```
autos.reset
```

### Script

```
#ms.autos.reset()
```

### Parameters

No known parameters.

### Return

Returns a script response object.

The `-autocompletes reset-` line is triggered by the client.

#### CLI

```
Success

-autocompletes reset-
```

#### Script

```
{
  ok: true
}
```

## Example

```js
function(context, args)
{
  return #ms.autos.reset()
}
```
