---
title: corps.hire
description: "Hires another user to a player corporation"
---

((corps.hire)) allows a player corporation owner or admin to hire another user.

### Security level

NULLSEC

## Syntax

### CLI

```
corps.hire { name: "example_user" }
```

### Script

```
#ns.corps.hire()
```

### Parameters

#### name (required)

The '((%Nname%))' argument specifies the target user.

#### rescind (optional)

The '((%Nrescind%))' argument specifies if a pending corp offer to the target user should be rescinded/revoked.

### Return

Returns a script response object.

#### CLI

```
>>corps.hire {name: "example_user"}
Success
```

#### Script

```
{
  ok: true
}
```

## Example

```js
function(context, args)
{
  return #ns.corps.hire({ name: "example_user" })
}
```
