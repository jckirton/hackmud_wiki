---
title: corps.quit
description: "Leave a player corporation"
---

((corps.quit)) allows a player corporation member remove themselves from the player corporation.

### Security level

NULLSEC

## Syntax

### CLI

```
corps.quit { confirm: true }
```

### Script

```
#ns.corps.quit({ confirm: true })
```

### Parameters

#### confirm (required)

The '((%Nconfirm%))' argument confirms quitting the player corporation.

### Return

Returns a script response object.

#### CLI

```
>>corps.quit { confirm: true }
Success
```

#### Script

```
{
  ok: true
}
```


## Example

```js
function (context,args)
{
  return #ns.corps.quit({ confirm: true })
}
```
