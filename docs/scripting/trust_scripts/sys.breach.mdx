title: sys.breach
description: "Breaches the caller's system"
---

((sys.breach)) breaches the caller's system.

### Security Level

NULLSEC

## Syntax

### CLI

```
sys.breach { confirm: true }
```

### Script

```
#ns.sys.breach({ confirm: true })
```

### Parameters

#### confirm (required)

The '((%Nconfirm%))' parameter confirms execution of ((sys.breach)).

### Return

Returns a script response object, or a string with usage info when called with parameters.

#### CLI

No parameters or invalid parameters:

```
>>sys.breach
Usage: sys.breach { confirm: true }
breaches sys
```

With ((confirm: true)):

```
>>sys.breach{ confirm: true }
Success

System has been breached.
```

With ((confirm: true)) on already breached system:

```
>>sys.breach {confirm:true}
Failure
sys currently breached
```

On uninitialized system:

```
>>sys.breach{ confirm: true }
Failure
sys not initialized
```

#### Script

No parameters or invalid parameters:

```
"Usage: sys.breach { confirm: true }\nbreaches sys"
```

With ((confirm: true)):

```
{
  ok: true
}
```

With ((confirm: true)) on already breached system:

```
{
  ok: false,
  msg:"sys currently breached"
}
```

On uninitialized system:

```
{
  ok: false,
  msg: "sys not initialized"
}
```

## Example

```js
function(context, args)
{
  return #ns.sys.breach({ confirm: true })
}
```
