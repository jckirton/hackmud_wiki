---
title: sys.status
description: "Returns the user's system status"
---

((sys.status)) returns the status of the user that runs it.

### Security Level

HIGHSEC

## Syntax

### CLI

```
sys.status
```

### Script

```
#hs.sys.status()
```

### Parameters

There are no known parameters.

### Return

Returns a string or object depending on the context.

#### CLI

Returns a string.

```
>>sys.status
-system status nominal-
```

or

```
>>sys.status
-system is breached-
```

#### Script

Returns an object with 3 entries:

- ((%Nhardline%)) is the remaining time of an active hardline in seconds, or `0` if hardline is inactive.
- ((%Ntutorial%)) is a string. Values are unknown.
- ((%Nbreach%)) is a boolean representing if the caller's system is currently breached.

```
{
  hardline: 0,
  tutorial: "",
  breach: false
}
```

## Example

```js
function(context, args)
{
  return #hs.sys.status()
}
```
