---
title: sys.upgrades_of_owner
description: "Displays the script owner's upgrades"
---

When called as a subscript in a script that is hosted by one user, ((sys.upgrades_of_owner)) allows the upgrades of the script owner to be seen by a different user running the script.

### Security Level

FULLSEC

## Syntax

### CLI

```
sys.upgrades_of_owner
```

### Script

```
#fs.sys.upgrades_of_owner()
```

### Parameters

#### filter

The '((%Nfilter%))' argument takes the same filter syntax as [[sys.upgrades:((sys.upgrades))]].

#### full

The '((%Nfull%))' argument takes a boolean. When the value is set to ((%Vtrue%)), ((sys.upgrades_of_owner)) will display the full detail arguments of the owner's upgrades.

#### i

The '((%Ni%))' argument takes a number, or an array of numbers, and specifies the index(es) to be displayed.

### Return

Returns a string or an object, depending on context.

#### CLI

When called from the CLI, returns a string with usage info.

```
>>sys.upgrades_of_owner
Usage: (in subscript) #fs.sys.upgrades_of_owner({filter:<optional filter specification>, full:<optional true or false>, i:<optional index or array>})
```

#### Script

When called as a subscript, has the same return types as [[sys.upgrades:((sys.upgrades))]].

```
[
  {
    i: 0,
    loaded: true,
    tier: 3,
    rarity: 2,
    name: "channel_count_v3",
    type: "chat"
  },
  {
    i: 1,
    loaded: true,
    tier: 3,
    rarity: 1,
    name: "char_count_v3",
    type: "script_space"
  }
]
```

## Example

```js
function(context, args)
{
  return #fs.sys.upgrades_of_owner({ filter: { loaded: true, tier: 3 } })
}
```
