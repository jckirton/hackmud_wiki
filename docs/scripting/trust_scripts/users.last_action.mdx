---
title: users.last_action
description: "Displays the time of a specified user's last action"
---

((users.last_action)) displays a timestamp from a specified user's most recent action.

### Security Level

FULLSEC

## Syntax

### CLI

```
users.last_action { name: "trust" }
```

### Script

```
#fs.users.last_action({ name: "trust" })
```

### Parameters

#### name (required)

((%Nname%)) takes a string or array of strings (max. 50), and specifies which users' last action shall be checked.

### Return

{/* Returns an array of objects containing keys ((%Nn%)) and ((%Nt%)).

((%Nn%)) is a string containing the name of the user, and ((%Nt%)) is a Date object of that user's last action.

If a lookup fails due to the user not existing, `null` will replace the object for that user's entry in the array. */}

Returns an array containing objects with the name of the user (((%Nn%))), and a Date of their last action (((%Nt%))).

If a specified user doesn't exist, their entry in the returned array will instead be `null`.

#### CLI

```
>>users.last_action { name: "trust" }
{
  n: "trust",
  t: "2024-01-16T21:43:11.439Z"
}
```

#### Script

```
[
  {
    n: "trust",
    t: "2024-01-16T21:43:11.439Z" // This is a Date object.
  }
]
```

## Example

```js
function(context, args)
{
	return #fs.users.last_action({ name: "trust" })
}
```
